# 研究宇宙的秘密

六章原生WebGL/Web Audio科普交互演示：[黑洞](index.html)、[早期宇宙](bigbang.html)、[宇宙网](cosmicweb.html)、[恒星](stellar.html)、[假想虫洞](wormhole.html)、[宇宙终局](heatdeath.html)。双击`index.html`即可运行，也可通过静态HTTP服务器访问。页面无需Node、安装包、构建步骤或联网，正文与MathML公式离线可读。

## 操作

拖动旋转，双指或滚轮缩放；聚焦场景后方向键旋转、加减键缩放。H隐藏/恢复HUD；触屏可用独立“恢复控制界面”按钮。小屏面板可折叠和滚动。弹窗支持Tab焦点约束、Escape关闭和焦点返回。

工具栏提供画质、统一音量、减少动态和暂停。音频由用户操作启动。减少动态冻结着色器时间，停止相机自动旋转、导演模式和自动演进，并降低更新频率；穿越直接完成状态切换。隐藏或暂停时停止动画时钟、挂起音频；恢复不会补算后台经过的时间。

## 模型范围

未导入NASA、ESA、EHT、JWST或其他机构的图像、星表、音轨或真实数据。黑洞和虫洞使用经验偏折，未实现RK4克尔或Morris–Thorne测地线积分；多光谱按钮提供示意配色。恒星阶段是教学形态拼接，质量只改变示意尺度。终局的常数w密度公式有明确假设，视觉大小映射不代表弗里德曼方程积分。质子衰变和重生是可选假设情景。

黑洞几何HUD采用克尔坐标半径公式；质量改变长度和引力时间单位，在固定归一化相机下图像保持不变。其余阶段HUD中的温度、压力、磁场、熵、质量和年龄均标为演示预设。声音来自本地振荡器；宇宙网页扫描程序节点投影，恒星页按AudioContext时间调度脉冲。

18项参数的公式、单位和声画/HUD关系见[参数与科学映射](参数与科学映射.md)。11项官方资料或原始论文的URL、年份、条件和代码符号见[科学来源账本](science-content.json)。没有明确日期的网页保留空年份。

## 结构

| 文件 | 职责 |
| --- | --- |
| `runtime.js` | 单一RAF、统一时钟、种子随机数、相机输入、GL编译链接和恢复、音频资源、画质与性能调节 |
| `common.js` | 工具栏、弹窗、标签和ARIA、可折叠面板、HUD恢复 |
| `math.js` | 矩阵计算与扫描事件投影 |
| `base.css` / `common.css` | 公共外观、响应式、焦点和错误布局 |
| `chapters/*.js` | 各章模型、控件、绘制和声景；不创建独立RAF |
| 六个HTML | 章节结构、配色和GLSL |

经典脚本支持`file://`。GL丢失后原位重建，保留参数和相机，释放旧监听、定时器、GPU资源和音频图。初始化失败显示诊断并停止渲染。

## 画质与性能

| 档位 | 像素上限 | 分辨率倍率 | 粒子比例 | 光线步进上限 |
| --- | ---: | ---: | ---: | ---: |
| 低 | 600,000 | 0.6 | 35% | 56 |
| 中 | 1,200,000 | 0.8 | 65% | 96 |
| 高 | 2,100,000 | 1.0 | 100% | 140 |

DPR上限2，倍率后仍受总像素预算约束。虫洞着色器的固定循环上限为90步，中高档也受该上限约束。粒子尺寸随画布高度缩放，低档保留关键粒子类型。自动模式观测提交耗时和帧间隔的较大值：持续超过28 ms约1.8秒且满足3.5秒冷却后降档；持续低于20 ms约12秒且满足12秒冷却后升档。手动档立即生效并保存偏好。

基准固定种子、相机和场景，采样24帧，以单像素同步回读确认渲染完成，报告墙钟P50/P95和超过50 ms的样本数。结果包含同步开销，不能当作纯GPU计时或完整显示帧率。[验收报告](完整验收报告.md)记录改造前快照、当前高档和低档的实测数据。

## 开发验收

要求Node.js 22+（全局WebSocket）和Chromium浏览器，无npm依赖。默认使用Windows Edge；`EDGE_PATH`或`CHROME_PATH`可指定浏览器。实际验收环境见JSON报告，不据此声明其他浏览器已验证。

```powershell
node verify_all_pages.js
$env:TEST_USE_HTTP = '1'
node verify_all_pages.js
Remove-Item Env:TEST_USE_HTTP
node verify_failure_paths.cjs
node verify_audio_events.cjs
```

`TEST_CORE=1`跳过音频信号、录音和性能基准，不能替代完整验收。`TEST_REPORT`指定报告路径；`TEST_FAULT=shader/navigation`供测试器自检使用。启动、CDP命令和页面就绪有超时，异常也生成JSON，失败退出码为1。每章使用独立浏览器/profile，隔离协议层跨导航的触摸状态；结束时清理。补充的单次音效测试覆盖啁啾、穿越和重生的静音、重复播放、暂停恢复与节点释放。

报告为`test-results.json`和`test-results-http.json`；自检为`runner-failure-results.json`；截图和六章WebM录音在`output/acceptance/file`及`http`。覆盖18项参数的最小/默认/最大值及高低档效果、全部阶段、四种视口、Pointer拖动/双指缩放/取消、键盘与弹窗、三次上下文恢复、音频启停/静音/调度和画质迟滞。固定帧比较全部RGB像素，容忍同GPU少量1/255量化差异，不使用跨GPU金图。

重测改造前基准运行`node benchmark_before.cjs`，只读`.backup-20261106`中的保留版本；完整验收后运行`node build_acceptance_report.cjs`更新汇总。原始[项目审阅与后续提示词](项目审阅与后续提示词.md)描述改造前问题；当前结果以[完整验收报告](完整验收报告.md)和[执行进度](执行进度.md)为准。
