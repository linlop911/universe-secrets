# 参数、模型和声画映射

基准日期：2026-11-06。18个滑块的实际上下界、默认值和像素证据由`acceptance-manifest.json`和两份`test-results*.json`登记。下面区分理论公式与显示设定。

## 坐标与时间

黑洞以引力尺度归一化；质量只改变理论几何读数和单位换算，固定归一化相机下图像保持不变。`rg=GM/c²`，采用`1.477 km × M/M☉`；`tg=GM/c³`采用`4.9255 μs × M/M☉`。克尔读数依据S9，换算常数依据S10。其余五页使用任意视觉长度，粒子位置不对应可观测距离目录。动画时间为秒，演示阶段轴无量纲，不是宇宙年龄或恒星寿命的数值积分。

## 18项参数

| 页面/控件 | 状态与计算 | 画面、声音和读数 | 模型范围 |
| --- | --- | --- | --- |
| 黑洞 `param-spin` | `spinVal → u_spin` | 经验轨道速度、盘内缘和能层；更新r+、rph、能层厚度、亮暗系数 | 理论读数与经验画面分开；未积分克尔测地线 |
| 黑洞 `param-mass` | `massVal`，M☉ | r+=rg(1+√(1−a*²))；rph=2rg[1+cos(2acos(−a*)/3)]；赤道厚度2rg−r+；tg随质量线性变化 | 固定无量纲相机下像素保持不变；坐标半径不等于阴影半径 [S9,S10] |
| 黑洞 `param-disk` | `diskVal → u_disk_density` | 盘辐射样本透明度乘0.8×diskVal | 显示强度，不求解吸积率或流体 |
| 早期宇宙 `param-epoch` | `currentEpoch/targetEpoch → u_epoch` | 0—5阶段插值；声音max(32,110−16×epoch) Hz；HUD阶段预设 | 时间、温度和比例不构成自洽宇宙学计算 |
| 早期宇宙 `param-inflation` | `inflationVal → u_inflation` | 暴胀阶段半径乘该系数 | 任意视觉倍率，不是暴胀势测量 |
| 早期宇宙 `param-dm` | `dmVal → u_dm` | 网格频率乘dmVal/0.268，主要在阶段4可见 | 默认0.268为显示设定；未解玻尔兹曼方程或N体运动 |
| 宇宙网 `param-dm` | `dmVal → u_dm_pot` | 丝状粒子位移速度随系数改变 | 经验流动速度，不是物质密度反演 |
| 宇宙网 `param-drag` | `dragVal → u_drag` | 气体x坐标减去0.7×dragVal；模式2突出气体 | 气体滞后示意，不是碰撞流体解 |
| 宇宙网 `param-lens` | `lensVal → u_lens` | 模式1的XY乘1+0.4L/(1+0.08r)；声化使用相同投影 | 图形放大，不是透镜方程解 |
| 恒星 `param-stage` | `currentStage/targetStage → u_stage` | 0—4阶段形态和预设HUD | 不同天体形态的教学拼接，不声称一颗恒星必经全部图像 |
| 恒星 `param-mass` | `massVal → u_mass` | 位置乘(M/25)^0.2 | 指数0.2为显示设定，不计算演化分支或遗迹类型 |
| 恒星 `param-spin` | `spinVal → u_spin` | 阶段4光束角=0.4×spin×动画秒；音频间隔1/spin秒 | 光束减速便于观察；音频按输入Hz调度，非实测射电波形 [S6] |
| 虫洞 `param-radius` | `throatRadius → u_throat_radius` | 经验偏折区域；孔径显示2b0 a.u. | 任意单位，不声称真实虫洞尺度 |
| 虫洞 `param-tension` | `energyTension → u_energy_tension` | 偏折强度1.8×b0×tension/r³ | 经验系数，HUD用a.u.；不是卡西米尔能量密度 |
| 虫洞 `param-fidelity` | `bellFidelity → u_bell_fidelity` | 灰度与彩色间的饱和度插值；HUD显示同值 | 旧变量名保留；界面改为饱和度，不计算量子保真度 |
| 终局 `param-stage` | `currentStage/targetStage → u_stage` | 0—4插值，含可选质子衰变情景 | 无量纲阶段，年代为情景预设，不是寿命预测 |
| 终局 `param-w` | `wVal → u_w` | ρ比=2^[−3(1+w)]；位置倍率clamp(ρ比^0.12,0.75,1.35) | 常数w密度公式；指数为显示设定。暗能量主导且w<−1/3时加速，不能单由w断言终局 [S11] |
| 终局 `param-hawking` | `hawkingVal → u_hawking` | 阶段2后透明度乘exp[−0.18H×max(0,stage−2)] | 余辉衰减，不是霍金温度或蒸发寿命 |

黑洞亮暗HUD系数采用`(1−0.7a*)^−3`的经验预设；着色器使用另一种轨道速度、引力红移和Doppler显示映射，HUD不代表逐像素通量比。所有非黑洞阶段HUD中的温度、压力、磁场、熵、质量和年龄数值均为演示预设，在页内标明，不登记成观测数据。

## 声音映射与生命周期

| 章节 | 输入与声音 |
| --- | --- |
| 黑洞 | 固定54/108/162 Hz三振荡器声景；合成扫频啁啾，未导入英仙座音轨 |
| 早期宇宙 | 同一个演示纪元控制频率，手动和自动演进均生效 |
| 宇宙网 | 程序节点经相机和透镜投影；X控制扫描和声相，Y选择五声音阶，节点脉动强度控制包络峰值。纯函数`CosmosMath.scanEvents`可复现事件 |
| 恒星 | 10/40 Hz验收样本记录实际Oscillator.start调度；每25 ms预调度未来100 ms内的脉冲，按AudioContext时间设置1/spin间隔 |
| 虫洞 | 108/114 Hz混合氛围和80→620→50 Hz穿越扫频；不宣称双耳节拍治疗或量子隧穿测量 |
| 终局 | 32.7 Hz低音和重生和弦；后者是可选动画的反馈 |

全部输出进入共享音量增益和压缩器；静音覆盖啁啾、穿越和重生等单次音效。音频图重复启停复用，短音节点结束后断开，退出或图形重建时关闭上下文。暂停和隐藏会挂起运行中的AudioContext，恢复后继续，没有后台时间追赶。
