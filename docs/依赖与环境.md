# 依赖与环境

## 直接打开（无需任何依赖）

六章页面是原生 HTML / CSS / JavaScript，双击根目录的 `index.html` 即可运行，`file://` 下正文、MathML 公式、三语内容与本地素材全部离线可读。浏览器需要支持 WebGL、Web Audio 与 ES2022；推荐 Chromium / Edge 现代版本。

`package.json` 声明 `private: true` 与 `engines.node >= 22`，**没有运行时依赖、没有构建步骤、没有 npm 安装要求**。`npm run ...` 只是本机命令的快捷入口，不是运行网站的前提。

## 开发验收依赖

| 用途 | 依赖 | 是否必需 |
| --- | --- | --- |
| 内容生成与全部验收脚本 | Node.js 22+（`global WebSocket`） | 开发/复现必需 |
| 浏览器自动化 | Chromium / Edge | 验收必需 |
| 导览录屏与海报 | FFmpeg | 仅 `npm run review` / 重录时需要 |
| PDF 首页重新提取 | Python + `pypdf` + `PyMuPDF`（见 `requirements.txt`） | 可选；已保存文本核对不需要 |

Node 脚本不依赖任何 npm 包，直接用 `node tools/...` 即可。`tools/paths.cjs` 是唯一路径来源，`tools/content-source.cjs` 是唯一内容生成逻辑。

## 环境变量

| 变量 | 作用 |
| --- | --- |
| `EDGE_PATH` / `CHROME_PATH` | 指定验收用浏览器可执行文件；未设置时 `tools/paths.cjs` 在标准安装位置查找 |
| `FFMPEG_EXE` | 指定 FFmpeg；未设置时自动定位 imageio-ffmpeg |
| `TEST_USE_HTTP=1` | 通过本地静态 HTTP 服务器运行验收，而不是 `file://` |
| `TEST_CORE=1` | 跳过音频、录音与性能基准的快速模式，不能替代完整验收 |
| `TEST_FAULT=stale/shader/navigation` | 测试器故障注入 |
| `TOUR_PAGE=index` | 仅重录单章导览 |
| `TEST_REPORT` | 覆盖验收结果 JSON 的输出路径 |

PowerShell 示例：

```powershell
$env:TEST_USE_HTTP = '1'
node tools/verify_all_pages.js
node tools/verify_experience.cjs
Remove-Item Env:TEST_USE_HTTP
```

## 常用命令

```powershell
npm run build       # 由 data/ 单向生成 app/content.js 与三语分镜稿
npm run verify      # file 模式完整回归 + 体验专项
npm run verify:faults
npm run verify:audio
npm run benchmark
npm run review      # 生成录屏海报与导览审阅页（需 FFmpeg）
npm run report      # 由 evidence/ 原始数据重建三份报告
npm run math        # 校验 MathML 转换台账
```

完整顺序与验收范围见 [README](../README.md)；已知限制与复测方式见[已知问题与复测记录](已知问题与复测记录.md)。

## 目录速查

| 目录 | 内容 |
| --- | --- |
| `app/` | 运行时脚本、样式、六章模型、素材、三语内容脚本 |
| `data/` | 唯一内容源、英日译文、界面词典、验收映射 |
| `tools/` | 生成、验收、录屏、报告脚本 |
| `docs/` | 本文件、分镜稿、科学映射、审核提示词、整改与已知问题 |
| `evidence/` | 结果 JSON；报告中的计数与日期都由这里汇总 |
| `output/` | 截图、录屏等生成物（大体积帧目录由 `.gitignore` 排除） |
| `archive/` | 历史性能基线；本地工作前快照不纳入版本控制 |
