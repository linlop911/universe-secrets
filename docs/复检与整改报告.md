## 二、本轮整改

1. **仓库分层**：工作前快照保存在 `archive/work-20261107/`，两个历史基线改名为 `archive/baseline-20261106`、`archive/baseline-20261107`；运行时资源归入 `app/`（含 `styles/`、`chapters/`、`assets/`），源数据归入 `data/`，工具归入 `tools/`，文档归入 `docs/`，结果归入 `evidence/`，截图录屏保留在 `output/`。根目录只保留交付入口与三份报告。删除 0 字节 `output/sources/paper.html`。
2. **路径单一来源**：新增 `tools/paths.cjs`，统一浏览器与 FFmpeg 定位（可用环境变量覆盖）、页面与运行时清单、各目录解析；HTTP 白名单由清单与素材数据自动派生。
3. **视觉系统 v2**：新增 `app/styles/design.css`，六页最后加载；统一深空底色、章节强调色光晕、衬线开场问题、细线导航、字幕式导览条、六个幕点与双栏观测对照构图，并提供小屏/矮视口规则与减少动态支持。
4. **叙事节奏**：`data/chapter-content.json` 六幕改为 0 / 6 / 14 / 24 / 33 / 39 秒的不等距节奏；`data/voiceover.json` 按该节奏重写；`app/experience.js` 把 `voice` 真正接入导览字幕条，并用幕点高亮与切幕动效表达节奏；按钮与计数改为由时长驱动。
5. **单向内容生成**：新增 `tools/content-source.cjs`，`tools/build_content.cjs` 只生成 `app/content.js` 与 `docs/六章分镜与旁白稿.md`，不再回写任何源文件；完整回归与体验专项都加入生成物新鲜度断言，`TEST_FAULT=stale` 可注入漂移验证失败可见。
6. **可证伪验收**：所有脚本去掉固定日期与固定计数；`tools/build_acceptance_report.cjs` 无论成败都生成报告、列出失败明细、由 `evidence/` 原始数据汇总计数与日期，并把历史告警纳入报告；性能验收加入 P95 1.0 ms / 长帧阈值；异常与外部请求改为整会话累计；故障自检从 3 项扩为 4 项（新增生成物漂移）。
7. **来源核对**：`tools/verify_pdf_source.py` 改为从已保存的 PDF 首页文本匹配关键词、由实际匹配片段生成证明并记录文本哈希，不再人工写回、不再依赖 fitz；`tools/audit_sources.cjs` 对 PDF 项不再自称内容已核对。
8. **数据契约**：`data/asset-manifest.json` 的 `localPath` 同步到 `app/`，原创图解登记 `assetOrigin`，官方素材要求 `assetUrl`，修复 5 项重复的处理说明；`tools/format_math.cjs` 作为数学台账的正式维护入口。
9. **约束保持**：`app/experience.js` 仍不含 `catch(` / `?.` / 额外 RAF / `setInterval`，`tools/verify_experience.cjs` 保留该源码断言；未新增静默兜底、伪造数据或降级分支。错误由验收捕获并如实报告。
10. **文档同步**：重写 `README.md`，新增本文件与 `docs/已知问题与复测记录.md`；三份报告与 `evidence/acceptance-evidence.json` 由生成器重建。
