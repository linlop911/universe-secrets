## 已知限制

1. 自动验收只在本机 Windows 无头 Edge 与四种模拟视口执行；没有实体手机、其他浏览器、屏幕阅读器或人工试听记录。
2. 中文旁白为文本，随导览逐幕显示；未合成口播音轨。录屏只包含本项目合成声景。
3. 重新提取 PDF 首页文本需要 `pypdf`，导出首页图需要 `PyMuPDF`；当前核对脚本不依赖二者。
4. 导览录屏与海报需要 FFmpeg（`FFMPEG_EXE`），审阅页由 `tools/build_review.cjs` 生成。
5. 六页 HTML 仍保留章节特有的内联配色与 GLSL；公共外观已收敛到 `app/styles/`，但历史内联块尚未逐条清理，属于后续维护项。
6. `app/experience.js` 按项目约束不含投机性兜底；数据字段缺失会导致明确异常，由验收脚本捕获并报告，不静默降级。
7. 「震撼」「感动」「好听」属于人工审阅目标，自动验收不作证明。
8. 英日文为页面文本与逐幕旁白；导览录屏与配音仍为中文版，未录制英日语语音轨。
9. 界面词典以中文原文为键；经 LSP 语义复查后补齐按钮、阶段名、弹窗标题与 telemetry 动态文案，现覆盖 178 / 179 条页面中文文本。仅 1 处跨行科学说明段落保留中文。后续新增文案需同时补 `data/i18n/en.json` 与 `ja.json`。
